# 요약
현대 사회에서 시각장애인들은 많은 불편함과 제약을 겪고 있다. 기존에 개발되어있는 시각보조 애플리케이션인 '<b>설리번플러스</b>'는 시각장애인들에게 카메라를 통해 인식한 정보를 알려주는 서비스를 제공한다. 그러나 해당 애플리케이션을 사용하여 제품명과 상세 정보를 확인하고자 할 때, 촬영된 이미지 내의 모든 텍스트를 인식하기 때문에 사용자에게 필요 없는 정보를 제공한다는 문제점이 있다.
따라서, 딥러닝 YOLOv5 기반 객체 인식 방식을 이용해 실시간으로 제품을 인식하여 그에 대한 정보를 제공하는 서비스를 제안한다.
